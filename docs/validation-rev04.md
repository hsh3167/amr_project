# Rev04 검증 기록

2026-11-09~10 KST 수행. 범위는 파일/배치/화면 기능이며 제작 승인이나 실물 주행 검증은 아닙니다.

## CAD와 STEP

- CadQuery 2.5.2에서 로컬 생성 후 STEP 재가져오기: 유효한 양의 체적 솔리드80개.
- GitHub Actions 생성 성공: [실행 기록](https://github.com/hsh3167/amr_project/actions/runs/42629989174).
- **Actions가 생성한 파일을 별도로 다운로드해 재가져오기**:80개 유효 솔리드, 경계484.2×566.7548×413.12mm, 지면Z0, 검증 JSON과 일치.
- 타이어 폭42.5/외경180, 축 평면10을 형상 경계에서 검사. 구동륜2개와 캐스터4개 휠의 실제 형상 경계 최저Z가 각각0임을 검사.
- 모터(타이어·케이스·축) 및 배터리 대 하판·모터브라켓·프로파일·드라이버의 선택적 교차 체적 검사: 겹침 없음. 전체 부품쌍/나사/케이블/캐스터 선회/하중/탄성 변형 검증으로 확대 해석하지 않습니다.
- 드라이버 더미를Y65에서85로 이동하여 배터리와 겹치던 영역을 제거했습니다.

## 공개 페이지

[GitHub Pages 배포](https://github.com/hsh3167/amr_project/actions/runs/42630054969) 성공. 공개 HTML/공통 부품 JSON/STEP/검증 JSON 모두HTTP200이며 Rev0.4와 V2.02, 폭42.5를 확인했습니다.

실제 브라우저에서 다음 항목을 확인했습니다.

- 3D 장면 렌더링과 모델의 전후 LiDAR2/카메라2/모터2/캐스터4 구성.
- TOP/FRONT/3D 시점 전환, 상판 숨기기와 복원.
- 분해50%/0% 변화, 회전 데모와 정지/시점 초기화.
- 실제 PNG 다운로드, 파일명 `amr-layout-rev04.png`; 저장된 TOP 및3D 이미지를 열어 육안 확인.
- LiDAR 상단의 겹친 면 표시에는 재질 깊이 보정을 적용했습니다. 이는 치수 또는 STEP 형상을 변경하지 않습니다.

웹에는 스캔선/치수선/숨겨진 암 예비영역 등 보조 형상이 있으므로 장면 전체 경계를 STEP 본체 경계와 동일시하지 않습니다. 웹 주행 모션은 개념 데모입니다.

## 남아 있는 기구·전장 확인

Ø180±2 타이어와 실제 압축량, GL-65-ASF 설치높이/컴파운드, 구동륜 정상반력, 단축 체결 스택과 토크반력 브라켓 강도, 배선과 커넥터 치수, 배터리팩 실측을 확인해야 합니다. 7S 완충29.4V의 회생전압 여유/드라이버 정격과 TiM571 최대28V 전원 분리 검토는 [설계 판단](engineering-decisions.md)에 정리했습니다. 모터 PDF 본문/도면 표의 사양 충돌과 열센서 핀 충돌은 [판독 기록](motor-datasheet-review.md)에 남겼습니다.
