# AMR 서스펜션 · Rev12b (6륜 독립 경첩 + 스프링, MISUMI STEP 상세화)

2026-11-12 사용자 결정: 6개 바퀴 모두 독립 서스펜션이고, 구조는 **단순하고 작아야** 한다. 수직 레일(Rev11)은 기울어지는 힘을 받을 가이드가 바퀴마다 필요해 부품이 많았다. 경첩은 핀 하나가 모멘트를 모두 받으므로 가이드가 필요 없어 가장 단순하다. 이전 개념은 git 이력에 있다: Rev09 `4643d47`, Rev10 `a5f5081`, Rev11 `5c308b1`.

## Rev12b 상세화·간섭 정리 (2026-11-14)

- **범프 스토퍼를 MISUMI `C-USLH10`(경제형 우레탄 스토퍼, 수나사)으로 바꿨다.** D10, 높이 17, M5×0.8 나사 7, 쇼어 A90. 암 바닥(6t)에 M5 탭으로 세우고, 하판을 관통한 M6 볼트(잼너트로 높이 조정)가 끝을 받는다. 우레탄 높이 17로는 암과 하판 사이(구동 45, 캐스터 28)를 채울 수 없어 볼트를 받침으로 남겼다. 나사 7이 6t 암 밑으로 1mm 나온다.
- 핀(CLBKHM10-78.5/-75), 부시(MPFZ10-10), C-USLH10은 MISUMI가 제공한 STEP 형상을 그대로 조립에 넣었다(`misumi_step_exact`). 스프링 STEP은 자유 길이 형상이라 그대로 쓰지 않고, 모델 스프링을 STEP의 사각 선재 단면(구동 3.75×1.875, 캐스터 3.25×1.625)과 피치(감김 8.75/4.75)로 바꿨다. 끝단 연마 코일은 생략했다.
- 핀 끝 M6 탭(최소경 4.92)에 맞춰 고정 나사 CB6-8의 체결부를 최소경으로 그렸다. 부시 슬리브와 플랜지 사이 R0.3 필렛이 암 구멍 모서리와 겹쳐, 암의 부시 구멍 입구에 0.5×45° 모따기를 넣었다.
- 전체 부품 쌍 검사(정지 자세 + 각 바퀴 상하 끝, 스프링 포함)에서 기존 검사가 보지 않던 간섭을 찾아 고쳤다: 하부 코너판이 3t 하판에 1mm 묻힘 → 판 위로 올리고 기둥 구멍(20.4 각)을 뚫음, 코너판과 LiDAR 기둥 겹침 → 27 각으로 축소, LiDAR 브리지가 주기둥을 관통 → 기둥 자리 노치, SICK 광학 외곽과 상부 원판 겹침 → 외곽 높이 3 축소, 자세별 스프링과 예압 심 겹침 → 기울어진 시트의 높은 쪽에 스프링을 맞춤. GL-65 캐스터 제조사 STEP 안에서 바퀴 허브가 포크 다리에 0.2mm 들어가는 겹침(26mm³)은 원본 그대로 두고 예외로 기록했다.
- Rev05 기준 부품(`--variant baseline`)은 바꾸지 않았다.

## Rev12a 소형화 (2026-11-13)

높이는 줄이지 않았다. 캐스터는 캐스터 높이 83 + 암 6 + 스프링 간격 28 = 하판 밑면 117로 고정이다. 구동 스프링은 CK68에서 짧은 형번(X-SWU21-60은 간격 −5.7mm·압축 여유 1.6mm, X-SWR21-45는 −7.4mm·접지하중 약 86~170N)을 검토했으나, 바닥 높이에 따라 구동륜 접지하중이 크게 흔들려 X-SWU21-70을 유지했다. 캐스터 암 단축(90→70)과 구동 암 단축(130→110)은 끝 기울기와 하중 변동이 커져 채택하지 않았다.

| 항목 | Rev12 | Rev12a |
|---|---|---|
| 구동 암 형상 | 바닥 + 전체 길이 옆벽 2개 + 끝벽 ±42.5 (트레이) | 바닥 + 핀 근처 날개 2개(핀 뒤 12, 앞 25) + 축 끝벽 ±20. 절곡 3회 동일 |
| 구동 암 폭(Y) | −42.5~+42.5 대칭 | −42.5~+21 비대칭(−Y: 스프링·범프 스토퍼, +Y: 부시만) |
| 구동 범프 볼트 | X±140, Y+20 | X±130, Y−25 (스프링과 같은 줄, 배터리 모서리와 7.5mm) |
| 구동 핀 | CLBKHM10-100 (카탈로그 최대) | CLBKHM10-78.5 |
| 구동 브래킷 볼트 | Y±25 | Y−25, +5 |
| 구동 모듈 외곽(Y) / 부품 부피 | 108.5mm / 158cm³ | 87mm / 104cm³ |
| 구동 암 질량 | 0.87kg | 0.48kg |
| 가공 판금 12개 합계 | 약 4.3kg | 약 3.4kg |

- 단순 정적 계산(6t 바닥 85mm 폭 기준): 3g 수직 충격에서 스프링 위치 굽힘 약 47MPa, 모터 정지 토크 11.7Nm에서 바닥 비틀림 약 11.5MPa·0.14°. 부시 간격이 85→63.5mm로 줄어 견인 모멘트에 의한 부시 하중이 약 34% 늘지만 투영 면압은 수 MPa 수준이다. 피로·충격·절곡부·실물 강성은 미검증이다.
- 옆벽이 없어져 하판 밑 Z97~117에서 구동 모듈을 가로지르는 X≈107~133 띠가 비었다. 하판 종방향 레일 후보 통로이지만, 캐스터 구간(Y±178~260)에서는 캐스터 스터드(X±113)·캐스터 판 볼트와 겹치므로 레일 길이나 캐스터 스프링 위치를 함께 정해야 한다(미검토).

| 4 | 스프링 1개 | 암 윗면과 **하판 밑면 사이에 바로** 둔다(행거 없음) |
| 5 | M8 스터드 + 너트 | 스프링을 관통한다. 하판 위 너트가 **처짐 스토퍼**(너트로 조정) |
| 6 | MISUMI `C-USLH10` 우레탄 스토퍼 + M6 볼트·잼너트 | 스토퍼는 암에 M5로 고정하고, 하판을 관통한 M6 볼트 끝이 우레탄 끝을 받는 **범프 스토퍼**(볼트로 높이 조정) |
| — | 5mm 예압 심 | 로봇암이 없을 때 뺀다 |

- 핀 축은 모두 진행 방향(Y)과 나란하다. 그래서 견인·제동력과 턱 반력의 앞뒤 성분이 암을 돌리지 않아 **전진·후진 거동이 같다**.
- 용접, 레일, 볼베어링, 행거가 없다. 주문 가공품은 레이저 절단·절곡품 12개(암 6, 브래킷 6)이고, 강판 합계 약 3.4kg이다(Rev12a).
- 하판 휠 웰 안쪽 경계를 X±145에서 ±175로 바꿨다(모터 케이스 안쪽 면 X±177.9). 구동 스프링이 하판 밑에 바로 들어가도록 하기 위해서다.

- 스프링은 MISUMI CK68, 핀은 p1_065(D10, L25~100, 0.1mm 단위), 부시는 p1_383(MPFZ d10: D14 m6, 플랜지 Ø22, L10~30, 하우징 14 H7)에서 2026-11-12에 확인했다. 부시 플랜지 자리 2.5mm를 둔다. Rev12a 구동 핀 날개 바깥면은 Y−42.5/+21이고 핀은 L78.5다. 스프링 허용 변형 여유는 구동 2.8mm, 캐스터 3.6mm(허용 변형 55%L=19.25, 2026-11-14 수정)이고, 하중 공차는 ±10%다.

## 남은 확인 사항

1. 부시 압입(Ø14 H7, 캐스터 탭은 구멍 위아래 살 3.5mm)과 압입 후 내경, 부시 슬리브가 판 안쪽으로 2mm 돌출하는 것, 핀 고정(귀 H7)과 축방향 유격을 확인한다.
2. 시제품 저울로 구동 약 128N, 캐스터 약 71N(55kg)을 확인한다. 심, 스터드 너트, 범프 볼트로 조정한다.
3. 6t 절곡(굽힘 반경), 암 탭 구멍과 귀 구멍의 정렬, 볼트 체결, C-USLH10 우레탄의 범프 충격 흡수량, 감쇠 부족(댐퍼 없음)을 검증한다. 우레탄 압축 변형은 모델에 넣지 않았다.
4. MISUMI CAD·가격·납기는 2026-11-14 kr.misumi-ec.com에서 로그인 후 확인했다(원본 `cad/vendor/*.st*p.gz`, 출처·SHA256은 `cad/vendor/provenance.json`, 가격은 [BOM](../bom/suspension_misumi.csv)).
   - STEP 실측(5개 모두 단일 유효 솔리드)이 모델 치수와 일치한다: 핀 D10·머리 Ø16×1.5·L78.5/75(플랜지 아래 기준), 부시 OD14·플랜지 Ø22×2·전체 10(슬리브 8), 스프링 OD21/ID13.5/L70, OD17/ID10.5/L35. 모델 치수는 바꾸지 않았다.
   - Rev12b부터 핀·부시·C-USLH10은 제공 STEP 그대로 조립에 들어간다(위 Rev12b 절). 스프링 강성·밀착 길이는 STEP에서 알 수 없어 카탈로그 값을 유지한다.
   - 가격(VAT 별도, 2026-11-14 사이트 조회): 핀·부시·스프링·C-USLH10·CB 나사 합계 212,580원(X-SWU21-70은 최소 주문 10개). 표준 체결품·판금 가공은 견적 전 추정 293,160원이다. 서스펜션 6모듈 예상 총액은 505,740원이며 공개 뷰어의 "BOM·예상 가격"에서 볼 수 있다. 참고 출하일은 늦은 품목 기준 2026-11-24이고, 가격·납기는 주문 전에 다시 확인한다.
5. 3t 하판·상판의 프로파일 보강은 미반영이다([판·서스펜션 검토](plate-suspension-review.md)).
