# 주행 동역학 시뮬레이션 · Pro 모델 / Eco 모델 (2026-11-21, 사용자 요청)

웹 뷰어의 두 페이지(Pro `index.html`, Eco `eco.html`) 왼쪽 **주행 동역학 시뮬레이션**에서 시험을 골라 실행하면, 계산 결과대로 CAD 3D 모델이 움직입니다.

- 하중·속도 그래프를 같이 보여 주고, **● 영상 저장**으로 MP4(지원하지 않는 브라우저는 WebM)를 받을 수 있습니다.
- **ⓘ 계산 내용** 버튼은 이 문서의 수식·파라미터·출처·판정 기준·민감도·현재 실행 결과를 모델 구성도와 함께 보여 줍니다.

## 구성

| 파일 | 역할 |
|---|---|
| `web/drive-sim.js` | 계산 엔진(외부 물리엔진 없음). `ecoParams`, `proParams`, `simulate`, `sweep` |
| `web/sim-ui.js` | 두 페이지 공용 UI: 조작부, 3D 재생, HUD·그래프, 녹화, 한계값 표, 계산 내용 창 |
| `cad/side_profile.py` | Pro CAD 하부 실루엣 → `cad-output/side_profile.json` (차체 / 보기 링크 / 뒤 캐스터 암) |
| `cad/p30/side_profile.py` | Eco CAD 하부 실루엣 → `cad-output/p30/side_profile.json` |
| `tools/drive_sim.mjs` | 한계 탐색 → `cad-output/drive_sim.json`(Pro), `cad-output/p30/drive_sim.json`(Eco) |

```powershell
.venv\Scripts\python.exe -m cad.side_profile
.venv\Scripts\python.exe -m cad.p30.side_profile
node tools/drive_sim.mjs all
```

## 모델

**측면(피치 평면) 2D 다물체**이며, 좌우는 같다고 보고 한 쌍으로 묶었습니다.

- **차체:** 전후·상하·피치 3자유도입니다.
- **부속 물체:** 두 종류가 있습니다.
  - **슬라이드:** 차체 법선 방향으로 움직이고, 예압 스프링과 스토퍼가 있습니다. 직각 방향은 강성 2e6 N/m로 구속합니다.
  - **핀 조인트:** 피벗을 페널티 2e6 N/m로 묶고, 스프링 토크와 회전 스토퍼를 둡니다.

| | Pro (Rev17f) | Eco (P30-7) |
|---|---|---|
| 구동부 | 보기 링크(좌우 합 10.4 kg, 모터·앞 캐스터 포함), 피벗 Y+60·Z87, 앞 캐스터 ±10 mm(±3.7°) | 수직 슬라이드(좌우 합 9.2 kg), ±10 mm |
| 스프링 | SWU21-60, 피벗 뒤 85 mm, 공칭 56.4 N/개 | SWU21-70, 공칭 120 N/개 |
| 앞 캐스터 | 보기 링크에 고정(구동륜과 함께 회전) | 차체에 고정 |
| 뒤 캐스터 | 90 mm 경첩 암 + **SWL18-30**(Rev17g, 바퀴 환산 33.0 N @장착, 18.3 N/mm, ±5 mm, 바퀴 1.8 mm 처짐 이후 스프링 느슨) → 수직 슬라이드로 근사 | 차체에 고정 |
| 스토퍼 | C-USLH10 우레탄(3e5 N/m/개 가정) 앞 40 mm / 뒤 85 mm → 960 / 4335 N·m/rad | 고무 4e5 N/m(가정) |

**공통 모델링**

- **접촉:** 페널티 방식으로, N = max(0, k·δ − c·δ̇)입니다.
  - 타이어는 300 N/mm/륜, 캐스터는 400 N/mm/개입니다.
  - 차체 실루엣 점은 3000 N/mm에 반지름 5 mm입니다.
  - 지형은 꺾은선이며, 면과 모서리 모두 접촉합니다.
- **마찰:**
  - **구동륜:** LuGre 모델입니다(μ 0.6, σ₀ 1e5 N/m, σ₁ 400 N·s/m). 정지 마찰까지 표현합니다.
  - **캐스터:** 구름 저항 0.02입니다.
  - **차체 하부:** μ 0.3입니다.
- **모터:**
  - 휠 속도 PI 제어입니다(Kp 7, Ki 35).
  - 토크 한계는 2·min(11.7, 4·(ω₀−|ω|)/(ω₀−ω정격))입니다.
  - 반작용 토크는 모터 고정자가 달린 물체에 걸립니다(Pro: 보기 링크, Eco: 차체).
- **적분:** 반암시적 오일러, Δt = 0.4 ms입니다. 재생은 60 fps입니다.
- **스프링:** 자리에 얹힌 스프링이라 밀기만 합니다(F = max(0, F₀ + k·s)). Rev17g 뒤 스프링은 처짐 쪽에서 느슨해집니다. 이전 스프링들은 행정 안에서 늘 눌려 있어 이 수정으로 결과가 바뀌지 않습니다(Eco 한계값 그대로).
- **가정값:**
  - 질량 55 kg, 무게중심 높이 250 mm(두 모델 같은 가정)입니다.
  - 차체 관성은 600×350 상자로 계산했습니다.
  - 보기 무게중심과 관성은 모터 3.15 kg + 캐스터 0.6 kg + 링크 분포로 추정했습니다.
- **엔진 변경 확인:**
  - 2026-11-21 Pro 추가 때 엔진을 슬라이드/핀 조인트 일반형으로 바꿨습니다.
  - Eco 결과는 이전 엔진과 위치 차이 1e-12 m 수준으로 같습니다.
  - Eco 한계값 표도 전 항목이 같습니다.

## 결과 해석

- **Pro가 나은 점: 꺾임 경사·단차·방지턱**
  - 보기 링크가 돌면서 구동륜이 지면을 따라가므로, Eco보다 구동륜 하중이 덜 빠집니다.
  - 단차에서는 앞 캐스터가 모서리에 걸리면 보기가 돌아 구동륜 하중이 앞쪽으로 넘어가고, 그 힘으로 캐스터를 밀어 올립니다. 그래서 Eco(18 mm)보다 높은 단차를 오릅니다.
  - 한계값의 실패 원인은 대부분 **보기 링크 스토퍼 도달**입니다. 링크가 ±3.7° 끝에 닿으면 구동륜이 더 내려가지 못해 하중을 잃습니다.
- **Pro가 약한 점: 순수 등판(17°, Eco 19°)**
  - 오르막에서 무게가 뒤로 쏠리면 앞 캐스터가 뜨고 보기는 스토퍼에 닿습니다.
  - 그러면 뒤 캐스터가 무게의 약 40%를 받고, 구동륜 하중이 375 N에서 약 290 N으로 줄어 18°부터 미끄러집니다.
  - Eco는 구동륜 하중을 스프링이 고정하므로 경사에서도 하중이 거의 그대로입니다.
- **Pro E-stop: 뒤 캐스터 들림이 이릅니다 (Rev17g 약 1.5~1.75 m/s², Rev17f 약 1.0)**
  - Rev17 보기 스프링이 뒤 캐스터 하중을 쌍당 약 81 N까지 줄였습니다.
  - **Rev17g(2026-11-21):** 뒤 스프링을 X-SWU17-35(바퀴 환산 3.63 N/mm)에서 SWL18-30(18.3 N/mm)으로 바꿨습니다. 정지 하중 배분은 그대로이고(구동륜 69.7%), 무른 뒤 스프링 때문에 차체가 앞으로 출렁이던 것이 줄어 들림 시작이 늦어졌습니다. 뒤 캐스터를 완전히 고정해도 2.25 m/s²라 효과의 대부분을 얻습니다(고정은 바닥 비틀림 0.3 mm에서 한쪽이 떠서 채택하지 않음).
  - 차체는 보기 피벗(Y+60)을 중심으로 앞으로 기울 수 있고, 이 회전을 막는 것은 뒤 캐스터와 보기 스프링뿐입니다.
  - 정적으로 보면 차체가 피벗을 중심으로 앞으로 기우는 시작점은 약 1.9 m/s²입니다. 급제동은 계단 입력이라 동적 과도로 더 낮은 감속에서 들립니다.
  - 실제 구동 제동 최대(평균 2.97 m/s²)에서는 여전히 뒤 캐스터가 최대 23 mm 뜹니다. 앞 스토퍼가 받아 전도는 없습니다.
  - CAD 손계산 `forward_pitch_onset_g 0.3`(무게중심 200 mm, 피벗선 기준)은 이보다 낙관적입니다. check.py 수정은 하지 않았습니다.
- **민감도:** 한계값을 스토퍼 강성 가정 1/3배와 3배로 다시 계산한 결과입니다(0.3 / 0.5 / 1.0 m/s).
  - **Pro:** 보기가 스토퍼에 닿은 채로 넘어가는 시험이 많아 크게 변합니다.
    - 경사: 14/16/17° ~ 7/9/16°
    - 방지턱: 56/60/70 ~ 26/36/66 mm
    - 단차: 19/30/38 ~ 21/27/27 mm
  - **Eco:** 1 m/s 방지턱(56~42 mm)을 빼면 거의 변하지 않습니다.
  - Pro 한계값은 우레탄 스토퍼 실물 강성을 측정해 다시 계산해야 합니다.
  - 등판 한계(17°)와 E-stop 결과는 이 가정에 거의 영향을 받지 않습니다.

## 한계와 주의

- 2D 모델이라 좌우 롤, 한쪽 바퀴만 오르는 경우, 캐스터 선회 오프셋은 계산하지 않습니다.
- 무게중심 높이·관성·타이어 강성·바닥 마찰·스토퍼 강성은 가정입니다.
- 착지 충격 하중(kN 단위)은 접촉 강성 가정에 따라 크게 달라집니다.
- 모터 발열과 배터리 전압 강하는 넣지 않았습니다.
- 설계 비교용입니다. 시제품 시험으로 확인해야 합니다.
