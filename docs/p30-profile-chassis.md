# Eco 모델 (P30 프로파일 샤시) · 저가형 별도 버전

상태: **P30-4 개념 설계·모델링, 실물 미검증** (2026-11-18). P30-3: 판재를 전부 얇은 SS400 강판으로 바꿔 원가를 Rev15 아래로 낮췄다. P30-4: 휠모터 고정을 절곡판에서 **평판 + 하우징 일체형 부시(A안)**로 바꿨다(절곡 각도 공차로 휠이 기우는 위험 제거). Rev15(판재 + 보기 링크)와 별개 버전이며 Rev15 파일은 바꾸지 않았다. 참고 컨셉: PICKR EP.4(알루미늄 프로파일 샤시, 구동륜만 서스펜션, 캐스터 4개 고정).

- 설계 원본: [`cad/p30/layout.json`](../cad/p30/layout.json), [`cad/p30/build.py`](../cad/p30/build.py), 검사 [`cad/p30/check.py`](../cad/p30/check.py)
- 실행: `.venv\Scripts\python.exe -m cad.p30 build` (STEP+GLB+검증 보고서 → `cad-output/p30/`), 검사만 `-m cad.p30 validate`
- 뷰어: [`eco.html`](../eco.html) (스트로크 슬라이더, 검증 요약, BOM) · BOM: [`bom/p30_bom.csv`](../bom/p30_bom.csv)

## 하중·강도 (단순 정적, 55kg, 무게중심 중앙·높이 250 가정)

검증 결과 표는 `cad-output/p30/build_report.json`이 원본이다(웹 뷰어 검증 탭도 이 파일).

| 항목 | 값 |
|---|---|
| 스프링 힘 (−10 / 0 / +10) | 66 / 120 / 174 N (길이 57.7 / 47.7 / 37.7, 허용 변형 38.5 이내) |
| 구동륜 하중 비율 | 44.5% (120N×2 / 540N) |
| 캐스터 1개 | 75N (암 없이 35kg이면 26N — 여전히 접지) |
| 견인 한계 (μ0.6) | 2륜 144N → 약 2.6 m/s². 정격 토크 힘 44N/바퀴보다 크다 |
| 전도 시작 가속 | 좌우 0.66g, 전후 0.98g (고정 캐스터 지지 다각형) |
| 부시 기울임 모멘트 | 최대 견인 시 14.5Nm(지면~플랜지 201mm) → 부시 2개가 나눠 각 173N(동정격 882N의 20%, 정격 수명식 약 6,700km). 구름 마찰(μ0.003) 약 1N = 스프링 힘의 0.9% |
| 덱 암 부재 (20kg×3g) | 3030 일반 단면 가정 굽힘 15.5MPa, 처짐 0.17mm |

구동륜 부시는 회사 재고 무급유 부시(EA-MFCNW20·MFINS20) 대신 MISUMI 볼 리니어 부시로 바꿨다(2026-11-15). 미끄럼 부시의 마찰(약 51N, 스프링 힘의 43%)로 가속 중 서스펜션이 굳던 문제가 사라지고, MFINS20 치수 미확인·뒤 하우징 가공도 없어진다. 남은 위험: 싱글 부시는 MISUMI가 큰 모멘트 하중에 권하지 않는다 — 여기선 2개가 나눠 받고 하중비 19%지만, 씰 저항(미포함)과 덜컹임은 시제품에서 확인한다. 마모가 보이면 더블형 C-LHFRW20(L80)으로 바꾼다.

**P30-4 휠모터 고정(2026-11-18):** 절곡 일체형(6t)은 절곡 각도 공차(소량 ±0.5~1°)가 그대로 휠 캠버가 되어 평판 + LHSS20으로 바꿨다(A안, 사용자 결정). 모터는 축 어깨(스페이서)와 M14 너트 사이에 판을 조이는 형상 구속이라 축방향으로 밀리지 않는다(약 50Nm에서 조임력 약 18kN ≫ 옆 하중 72~200N). 너트 풀림 방지(나일론 너트 또는 Nord-Lock + 나사 고정제, 조임 표시)는 필수다. 하우징 1개 반력은 최대 견인 시 약 135N(P30-5, LHSS16 동정격의 17%, 지면~하우징 중심 175.6mm; 정확한 값은 `statics`)으로 P30-3 부시(173N)보다 낮다.

## 주행 동역학 시뮬레이션 (2026-11-21, 사용자 요청)

웹 `eco.html` 왼쪽 **주행 동역학 시뮬레이션**에서 시험을 골라 실행하면, 계산 결과대로 3D 모델이 움직입니다. 하중·속도 그래프가 같이 표시되고, **● 영상 저장**으로 MP4(지원하지 않는 브라우저는 WebM)를 받을 수 있습니다. 한계값 표의 값을 누르면 그 조건으로 재생합니다.

- **모델:** `web/drive-sim.js`, 측면 2D 다물체.
  - **차체:** 전후·상하·피치 3자유도.
  - **구동륜:** 좌우를 1개로 묶었습니다. 수직 슬라이드 + SWU21-70 예압 2×120 N + ±10 스토퍼, 축 수직 방향은 강성 조인트입니다.
  - **캐스터:** 앞뒤 2쌍, 자유 회전하는 강체 원입니다.
  - **접촉:** 차체 하부·앞뒤 면과 구동 캐리지 하부를 CAD 실루엣(`python -m cad.p30.side_profile` → `cad-output/p30/side_profile.json`)으로 넣어 지형과 접촉시킵니다. 패널티 접촉입니다.
  - **타이어 마찰:** μ 0.6, LuGre 강모 모델로 정지 마찰을 표현합니다.
  - **모터:** 휠 속도 PI 제어. 토크 한계는 스톨 11.7 Nm(전류 한계)이고, 정격점 4 Nm/500 rpm에서 무부하 600 rpm까지 선형으로 줄어듭니다.
- **한계값:** `node tools/drive_sim.mjs` → `cad-output/p30/drive_sim.json`. 격자 탐색이며, 첫 실패가 나면 그 시험은 멈춥니다.
- **가정:** 질량 55 kg, 무게중심 높이 250 mm(load_case), 차체 관성(600×350 상자), 타이어 강성 300 N/mm/륜, 캐스터 선회 오프셋 무시, 좌우 대칭(롤 없음). 시제품 시험으로 확인해야 합니다.

| 시험 (통과 한계) | 0.3 / 0.5 / 1.0 m/s | 한계 다음 값의 실패 원인 |
|---|---|---|
| 경사: 평지 → 경사 진입(꺾임 모서리 그대로) | **5/7/13°** | 경사 아래 꺾임에서 앞 캐스터가 먼저 올라가 차체가 들리면, 구동륜이 스트로크(−10 mm)를 넘어 하중을 잃습니다. 0.3 m/s는 −10에서 하중 부족, 0.5 m/s는 들림. 속도(관성)가 클수록 통과각이 큽니다 |
| 경사 위 출발(정지 1 s → 재출발, 꺾임 없음) | 최대 토크 **19°** · 정격 4 Nm 연속 **8°** | 20°: 구동륜 마찰 한계. 정격 9°: 모터 토크 부족 |
| 직각 단차 | **18/18/18 mm** | 앞 캐스터(Ø64)가 모서리에 걸립니다. 19 mm에서 밀어 올리는 데 약 250 N이 필요하지만 구동륜 마찰은 약 195 N입니다 |
| 방지턱(경사 1:2, 윗면 40) | **22/32/42 mm** | 구동륜이 턱 위에 오르면 스프링이 끝까지 눌려 캐스터 4개가 뜨고, 로봇이 구동륜 위에서 앞뒤로 흔들립니다(피치 최대 약 10°). 앞 캐스터가 내려앉을 때 순간 하중은 2 kN 이상입니다 |

- **E-stop 구동 제동 (1 m/s, μ 0.6, 구동륜만 제동):** 평균 감속은 최대 **3.29 m/s²**(순간 3.64), 감속 명령을 더 키워도 바퀴만 미끄러집니다. 전도 위험은 없습니다.
  - 미끄럼 한계 = μ × (스프링 예압 240 N + 구동부 자중 약 90 N) / 55 kg ≈ 3.6 m/s².
  - 수계산 보고서의 2.62 m/s²(`traction_accel`)는 구동부 자중을 빠뜨린 값입니다.
- **뒤 캐스터 들림 시작:** 6바퀴 모두 a/g 마찰로 미끄러지는 이상 제동을 가정하면 **4.5 m/s²(0.46 g)까지 들림이 없습니다**. 그보다 크면 뒤 캐스터가 들렸다가 내려옵니다.
  - 구동륜 하중이 스프링으로 고정되어 피치 모멘트를 캐스터만 받기 때문에, 수계산 0.98 g(강체 지지 다각형)보다 훨씬 작습니다.
  - 실제 구동 제동 최대 감속(3.64 m/s²)과의 여유는 약 25%입니다. 바닥 마찰이 0.6보다 크면 여유가 줄어듭니다.
- **완전 전도:** 0.5~2 m/s, 이상 제동 **15 m/s²(1.5 g)까지 없습니다.**
  - 무게중심이 앞 캐스터를 넘으려면 약 54 J이 필요하지만, 2 m/s 운동에너지가 110 J이어도 제동 중에 대부분 소산됩니다.
  - 좌우 전도(롤)는 2D 모델 밖입니다. 수계산 0.66 g를 유지합니다.
