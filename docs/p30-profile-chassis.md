# P30 프로파일 샤시 · 저가형 별도 버전

상태: **P30-4 개념 설계·모델링, 실물 미검증** (2026-11-18). P30-3: 판재를 전부 얇은 SS400 강판으로 바꿔 원가를 Rev15 아래로 낮췄다. P30-4: 휠모터 고정을 절곡판에서 **평판 + 하우징 일체형 부시(A안)**로 바꿨다(절곡 각도 공차로 휠이 기우는 위험 제거). Rev15(판재 + 보기 링크)와 별개 버전이며 Rev15 파일은 바꾸지 않았다. 참고 컨셉: PICKR EP.4(알루미늄 프로파일 샤시, 구동륜만 서스펜션, 캐스터 4개 고정).

- 설계 원본: [`cad/p30/layout.json`](../cad/p30/layout.json), [`cad/p30/build.py`](../cad/p30/build.py), 검사 [`cad/p30/check.py`](../cad/p30/check.py)
- 실행: `.venv\Scripts\python.exe -m cad.p30 build` (STEP+GLB+검증 보고서 → `cad-output/p30/`), 검사만 `-m cad.p30 validate`
- 뷰어: [`eco.html`](../eco.html) (스트로크 슬라이더, 검증 요약, BOM) · BOM: [`bom/p30_bom.csv`](../bom/p30_bom.csv)

## 하중·강도 (단순 정적, 55kg, 무게중심 중앙·높이 250 가정)

검증 결과 표는 `cad-output/p30/build_report.json`이 원본이다(웹 뷰어 검증 탭도 이 파일).

| 항목 | 값 |
|---|---|
| 스프링 힘 (−10 / 0 / +10) | 66 / 120 / 174 N (길이 57.7 / 47.7 / 37.7, 허용 변형 38.5 이내) |
| 구동륜 하중 비율 | 44.5% (120N×2 / 540N) |
| 캐스터 1개 | 75N (암 없이 35kg이면 26N — 여전히 접지) |
| 견인 한계 (μ0.6) | 2륜 144N → 약 2.6 m/s². 정격 토크 힘 44N/바퀴보다 크다 |
| 전도 시작 가속 | 좌우 0.66g, 전후 0.98g (고정 캐스터 지지 다각형) |
| 부시 기울임 모멘트 | 최대 견인 시 14.5Nm(지면~플랜지 201mm) → 부시 2개가 나눠 각 173N(동정격 882N의 20%, 정격 수명식 약 6,700km). 구름 마찰(μ0.003) 약 1N = 스프링 힘의 0.9% |
| 덱 암 부재 (20kg×3g) | 3030 일반 단면 가정 굽힘 15.5MPa, 처짐 0.17mm |

구동륜 부시는 회사 재고 무급유 부시(EA-MFCNW20·MFINS20) 대신 MISUMI 볼 리니어 부시로 바꿨다(2026-11-15). 미끄럼 부시의 마찰(약 51N, 스프링 힘의 43%)로 가속 중 서스펜션이 굳던 문제가 사라지고, MFINS20 치수 미확인·뒤 하우징 가공도 없어진다. 남은 위험: 싱글 부시는 MISUMI가 큰 모멘트 하중에 권하지 않는다 — 여기선 2개가 나눠 받고 하중비 19%지만, 씰 저항(미포함)과 덜컹임은 시제품에서 확인한다. 마모가 보이면 더블형 C-LHFRW20(L80)으로 바꾼다.

**P30-4 휠모터 고정(2026-11-18):** 절곡 일체형(6t)은 절곡 각도 공차(소량 ±0.5~1°)가 그대로 휠 캠버가 되어 평판 + LHSS20으로 바꿨다(A안, 사용자 결정). 모터는 축 어깨(스페이서)와 M14 너트 사이에 판을 조이는 형상 구속이라 축방향으로 밀리지 않는다(약 50Nm에서 조임력 약 18kN ≫ 옆 하중 72~200N). 너트 풀림 방지(나일론 너트 또는 Nord-Lock + 나사 고정제, 조임 표시)는 필수다. 하우징 1개 반력은 최대 견인 시 약 135N(P30-5, LHSS16 동정격의 17%, 지면~하우징 중심 175.6mm; 정확한 값은 `statics`)으로 P30-3 부시(173N)보다 낮다.

P30-5(2026-11-18, 사용자 지시 1~3번): 스프링을 최소 주문 1개인 SWU21-70으로(−23,760), 가이드를 D20→D16(LHSS16·SFJW16, −21,524)으로 바꿔 −45,284원. 같은 날 로그인한 MISUMI Korea에서 사양·가격을 확인했다(VAT 별도, 재고 기준). 더 줄이려면 LHSS12·SFJW12(하우징 13,298 + 축 7,106원, 추가 약 −37,000원)가 있으나 동정격 412N·정정격 598N이라 3g 충격 여유가 작아 택하지 않았다.

Rev15(보기 링크)의 금액 확정 항목 합은 약 428,930원(서스펜션 336,088 + 브래킷 50,000 + LCD·스피커 브래킷 29,698 + 체결·전장 지지 13,144)이고, 하판·상판 3t 강판과 2020 프로파일은 미정이라 빠져 있다. 같은 판금 단가로 넣으면 약 45~46만원 → P30-4(437,436)는 약 2만원 싸다(금액 확정 항목만의 428,930원보다는 약 8,500원 비싸다). 가공품 단가는 모두 견적 전 추정이다(Rev15 `bom/suspension_misumi.csv`와 같은 기준: S355 6t 평판 4,000, 8t 평판 5,000, 3t 2회 절곡 12,000).

질량(빌드 보고서 `fabricated_mass_kg`): 판재 5.7→9.1kg, 구동 가공품·브래킷 5.7→9.8kg, 프로파일 7.0kg — 가공품 합계 약 +7.5kg. 캐리지+액슬벽은 스프링 아래 질량이라 바퀴당 약 0.8kg(Al 10t 두 장 1.1kg → 강 6t 한 장 1.9kg) 늘었다. 설계 질량 55kg 기준 정적 계산은 그대로 두었다. P30-4: 구동 가공품·브래킷 9.8→13.8kg — 10t 액슬판(약 3.2kg/장)이 무거워 스프링 아래 질량이 바퀴당 약 1.5kg 더 늘었다. 하우징 사이·축 아래 비하중 영역을 레이저로 따내면 줄일 수 있다(미적용).

## 배치

- 배터리: 회사 STEP을 90° 돌려 긴 변을 Y로, 중앙 3mm 패드 위(윗면 약 Z242 < 상부 프레임 255).
- 모터 드라이버: **ZLTECH ZLAC8015D 1대**(2채널, 매뉴얼 외곽 168×89×29.7). P30-5b에서 상자 2개를 대체했다. 배터리 오른쪽(X+106)에 세워서(좁은 면 아래, 긴 변 Y; 매뉴얼이 방열에 권장) 놓는다. 입력 20~48VDC, 채널당 15A·피크 30A, 홀+A/B 엔코더, CANopen/RS485. 컨트롤러 PCB + 컴퓨터: 앞쪽 중앙. 전원 분배: 앞 오른쪽.
- LCD: 앞면 중앙, 15° 위로, 3t 브래킷 발을 바닥판 너머 앞 하부 레일 T너트에 체결.
- 스피커: 뒤 왼쪽, 그릴 뒤(−Y). DC/DC: 뒤 중앙 DIN 레일.
- LiDAR TiM571: **대각 모서리(앞 왼쪽·뒤 오른쪽)에 모서리 기둥 대신** 바닥판 위 SS400 3t 판에 놓는다. 스캔면 Z201.8로 상부 프레임 아래, 하부 프레임 위. 마름모 외곽이 모서리에서 약 38mm 튀어나온다(범퍼 고려 필요). 뷰어(`eco.html`)는 Rev15와 같이 CAD 상자 3개 대신 SICK 공식 TiM5xx 공용 STL(`web/vendor/sick/sick_tim_5xx.stl`)을 플레이트 윗면에 얹어 표시한다(STL을 못 읽으면 CAD 상자로 대체). CAD(STEP) 쪽 LiDAR는 Rev15와 같은 3부품(바닥 36mm·광학부·상단 디스크) 상자 형상이다.
- 카메라 Astra Mini Pro 2개: 상부 앞 레일 밑 SPCC 3t 절곡 브래킷 선반 + 출력 쐐기, X±140, Y282, Z239, **바깥 5°**·아래 10°.
- 카메라 FOV 검사(`check.camera_fov`): 깊이 FOV 58.4°×45.5° 피라미드(1.5m)를 카메라 STEP 앞면의 광학부 3곳(x −28 렌즈 경통, −3 가운데 렌즈, +27 창; 어느 것이 깊이 카메라인지는 미확인이라 셋 다)에서 만들어 모든 부품과 불리언. **알루미늄 프로파일은 어느 카메라 시야에도 없다.** 바깥 15°일 때 왼쪽 카메라 바깥쪽 광학부(x −28) 시야에 앞 왼쪽 LiDAR가 화면의 7.9%(최근접 29mm) 걸려 바깥 각도를 5°로 줄였다(6° 이하부터 가림 0, 1° 여유). 대신 두 카메라를 합친 좌우 시야가 ±44.2°→±34.2°로 좁아진다 — 옆은 LiDAR가 본다.

## 미해결

1. 리니어 부시 씰 저항·덜컹임, 두 축 평행도(홀더 구멍 위치 공차) 시제품 확인. 10t 열연 강판 액슬판의 평면도(하우징 두 장착면 사이)가 휠 캠버에 들어가므로 납품 판 평면도 확인, 필요하면 하우징 자리만 면삭. 수명이 부족하면 더블 하우징.
2. 3030 프로파일 실제 단면(재고 품번)·끝 탭 여부·히든 커넥터 방식 확인.
3. 시제품에서 슬라이드 마찰·덜컹임, 스프링 예압(120N) 대비 실제 견인, 캐스터 4점 접지(프레임 비틀림) 확인. 캐스터 높이 83(CAD)/82(카탈로그) 차이 1mm는 고정 캐스터라 그대로 휠 높이 차이가 된다 — 코너판 심으로 맞춘다.
4. LiDAR 모서리 돌출 보호, 배터리 고정 끈, 비상정지 스위치 위치(덱 위 권장), 배선 경로.
5. 로봇암 볼트 패턴·반력이 정해지면 덱 암 부재와 기둥 보강 재검토.
6. 가격은 견적 전 추정(가공품 위주, Rev15 `bom/suspension_misumi.csv`와 같은 판금 단가 기준). 구동부 절곡은 없어졌다(P30-4). 강판은 녹 방지(도장·아연) 비용이 추가될 수 있다.
7. 강판 전환으로 가공품 질량이 늘었다(아래 원가 절). 55kg 설계 질량 안에 있는지 실측 후 재확인.
