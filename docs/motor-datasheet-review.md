## 전기 성능 — 본문 p.3~4를 설계 기준으로 적용

| 항목 | 값 |
|---|---|
| 정격 / 사용전압 | 24V / 18~30V |
| 정격 토크 / 속도 / 전류 | 4N·m / 500rpm / 10A |
| 스톨 토크 / 전류 | 11.7N·m / 30A, 토크 표기1min |
| 무부하 속도 / 전류 | 600rpm / ≤1.5A |
| 엔코더 | 1024±1라인, 자석식, 단일종단 A/B |
| 엔코더 전원 | 4.5~5.5V, 대표5V |
| 구성 | 3상, 30극, 단축 |

4Nm×500rpm의 기계출력은 약209W입니다. 도면의250W 표기를 본문 동작점과 같은 출력이라고 단정하지 않습니다. 1024라인의 A/B 4체배는 드라이버가 지원할 때4096count/rev로 **계산**되며 4096라인 엔코더가 아닙니다. Ø180에서 이론 직진 환산은 0.138mm/count이지만 미끄럼/처짐/유효반경 오차는 별도입니다. 500rpm 환산속도4.71m/s는 모터 정격점일 뿐 학생 실험용 AMR 목표속도가 아닙니다. 초기 속도 제한 예0.3m/s(약31.8rpm)는 제어 설계 가정입니다.
