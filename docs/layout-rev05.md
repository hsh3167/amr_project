# Rev05 — 대각 LiDAR와 알루미늄 프로파일 배치

2026-11-10. 기존 모터 스펙과 바퀴 접지 조건은 유지하고 센서·전장·지지 구조를 재배치했습니다. 아래 좌표는 본 프로젝트 설계값이며 타사 로봇의 치수를 복사한 값이 아닙니다.

## 왜 대각 배치를 택했는가

270° 센서 각각에는90° 사각이 있습니다. 전방좌측의 사각을 우후방 차체 안쪽으로, 후방우측의 사각을 좌전방 차체 안쪽으로 향하게 하면 외부 양 측면과 모서리를 상호 보완하도록 배치하기 쉽습니다. 이번 변경은 상판을 적재/로봇암용으로 비우고 스캔면을 낮추는 목적도 있습니다. Rev04의 상판 위 전후 배치 역시 가림이 없다면 유효할 수 있습니다. 센서 위치를 옮겼다는 이유만으로 자동으로360° 검출이 보장되지는 않습니다.

전체 STEP 경계는 **546.5×606.5×307mm**입니다. 센서를 낮춰 전체 높이는 줄었지만 코너 돌출로 폭/길이는 늘었습니다. 이동 통로/보호범퍼는 이 증가를 반영해야 하며 커넥터·케이블 및 실제 캐스터 선회 엔벨로프는 추가됩니다. 센서 보호대는 광학면 아래에 두고 스캔면을 가리지 않도록 후속 설계합니다.

스캔240.83은 SICK 도면의62.46에 커넥터 높이차15.37을 더한77.83을 단순화 엔벨로프 하단163에 더한 배치 기준입니다. 제조사 상세 CAD와 실제 원점 위치가 없는 상태에서의 **기준면 대응 가정**이며 고정밀 센서보정값이 아닙니다. 스캔면 아래 물체/턱·구덩이는2D LiDAR만으로 해결하지 못합니다. 카메라도 최소거리와 시야/구조광 간섭을 시험해야 합니다.

## 기둥과 체결

모든 수직 기둥은 알루미늄20×20 T슬롯 프로파일로 모델링했습니다. 주기둥183mm×4, 센서지지40mm×4로 절단 길이를 단순화했습니다. 재질은 사용자 확정사항이고 단면20mm와 슬롯/보어는 일반화한 설계 가정입니다. 제조사 제품 단면·합금·접합부·끝단 탭·강도 확인 전 최종 발주/가공 치수로 사용하지 않습니다. 작은 길이 지지대는 절단·탭 작업성과 체결공구 접근도 확인합니다. 센서 어댑터와 수평 브라켓은 판재입니다.

## 검증

STEP 재가져오기:85개 양의 체적/유효 솔리드,6개 휠 최저Z0. 센서 본체 대 주기둥/상판/배터리/전장/카메라, 카메라 대 주기둥/상판의 선택적 교차체적 검사에서 겹침 없음. 실제 나사·케이블·열·변형과 전체 부품쌍 간섭을 모두 검증한 것은 아닙니다.

`cad/validate_layout.py`는 보수적인 구동륜/상판 투영 외곽에서50/200/500/1000mm 여유를 둔 네 사각 경계의404점씩, **총1616표본**을 검사합니다. 270° 시야와 스캔면을 지나는 주기둥의 가림을 반영했으며 표본 모두 최소한 센서 하나에 가시입니다. 연속 전영역/반사체/투명체/실제 성능/안전인증을 의미하지 않습니다. 커버·하네스·향후 로봇암은 후속검증 대상입니다.

## CAD 도구

**CadQuery 2.5.2 + OpenCascade STEP**으로 만들고, **Three.js**로 웹에 표시합니다. BD WARE/build123d 모델로 변환하지 않았습니다. 사용자 확인에 따라 CadQuery를 유지합니다. 배치의 원본은 `cad/layout.json`, 부품 치수의 원본은 `cad/parts.json`입니다.
