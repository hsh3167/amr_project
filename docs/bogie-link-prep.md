# 보기 링크(앞 캐스터 + 구동륜) 준비 메모

상태: **준비만 함, 설계 전** (2026-11-14). 사용자가 보유 부품 정보를 제공한 뒤 새 구조를 설계한다. 그때까지 Rev14(6륜 독립 경첩)는 그대로 유지한다.

## 목표 (사용자 지시)

- 앞 캐스터와 구동륜을 보기 링크(bogie)로 묶은 구조를 새로 만든다.
- 사용자가 이미 가지고 있는 부품을 쓴다. 부품 정보는 추후 제공된다.

## 사용자에게 받을 정보

부품마다 아래를 알려 주면 된다. STEP이 있으면 `C:\AI_Work\part cad\`에 두고 경로만 알려 주면 된다(원본은 `cad/vendor/*.gz` + `provenance.json` 방식으로 보관).

1. 품번·제조사(또는 자작 여부), 보유 수량
2. STEP 또는 도면, 없으면 주요 치수: 축/구멍 지름, 베어링 형번, 볼트 패턴, 두께, 재질
3. 보기 피벗에 쓸 부품: 축, 베어링/부시, 고정 방식
4. 스프링·댐퍼를 같이 쓸지, 쓴다면 형번과 강성
5. 링크 판으로 쓸 판재(두께, 재질) — 절곡 3t 제한과 맞는지

## 설계 전에 정할 것

- 보기 피벗 축 방향(좌우 X축 = 앞뒤 시소, 또는 진행 방향 Y축)과 위치
- 뒤 캐스터: 현재 경첩 유지 / 고정 / 함께 링크
- 피벗에 스프링을 둘지(순수 보기 vs 스프링 보기), 전도·스텝 높이 목표
- 구동륜 하중 비율 목표(현재 약 47%)

## 구현 준비 (코드 구조 계획만)

- 새 개념은 `layout.json`의 `suspension`에 새 블록으로 추가하고, 현재 경첩 블록은 보존한다(개념 선택 키로 전환).
- 기존 검증을 그대로 재사용한다: 정지 자세 전 부품 간섭, 바퀴별 행정 끝 간섭, 접촉 연결(떠 있는 부품) 검사, 캐스터 선회 검사, Rev05 비교.
- 뷰어 포즈 슬라이더는 보기 각도 기준으로 바뀔 수 있다.

참고 이력: Rev10 시소 개념은 커밋 `a5f5081`에 있다(2026-11-12 사용자 결정으로 독립 경첩으로 대체됨).
