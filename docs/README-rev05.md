## Rev05 배치 변경

Neobotix MPO-700의 대각 스캐너 옵션을 참고해 LiDAR를 **전방 좌측(-220,+250) / 후방 우측(+220,-250)**으로 이동했습니다. 각270° 스캔 영역은 바깥쪽, 사각90°는 차체 안쪽을 향합니다. 스캔면은 공칭약241mm이며 실제 광학 원점과 TF는 실물 확인 대상입니다. 상판 위 공간을 비우고 낮은 장애물 감지를 개선하려는 설계입니다. 전후 중앙 배치도 높은 위치에서는 유효할 수 있으므로 대각 배치가 모든 조건에서 우월하다는 의미는 아닙니다.

카메라2개는 상판 아래 전방±90mm/Y278/Z275에 배치하고 좌우±15°/하향10°를 가정했습니다. 카메라 프로파일 행거는 Z263~303으로 스캔면 위에만 위치합니다. 배터리는 낮게 유지하고, 전방Y180에 제어기, 후방Y-200에 전원 분배/DC-DC 공간, 양측에 드라이버를 배치했습니다.

모든 수직 기둥은 **알루미늄 프로파일**로 확정했습니다. 현재 공칭20×20 T슬롯과 중앙 보어는 구매품 미지정 상태의 범용 형상입니다. 절단 길이는 주기둥183mm×4, 센서지지40mm×4이며 접합부/하중 검증 후 제작합니다.

## 현재 레이아웃 [설계 가정]

현재 STEP 본체 경계는 **W546.5×L606.5×H307mm**, 배선 및 회전 캐스터의 전체 스위프는 제외됩니다. 상판420×550×t4, 하판390×530×t4, 수직 알루미늄20×20 프로파일8개(주기둥4+센서지지4), 구동륜 트랙422입니다. 타이어 중앙은 X±211/Z90. 도면 축 길이를 반영해 케이스 외측면은 X±242.1까지 나옵니다. 상세 케이스 형상은 가정이므로 실제 최대외형은 제조사 CAD/실측으로 검증합니다. 대각 LiDAR 엔벨로프가 기존 구동륜 폭보다 돌출하므로 통로 폭·충돌 보호를 새 경계546.5mm 기준으로 검토합니다.

캐스터 상부 장착면은 **Z82**, 하판 밑면 **Z116**으로 공칭 드롭 **34mm**를 적용했습니다. 바퀴6개는 CAD에서 Z0에 놓이지만 실물의 동시접지/구동륜 접지하중은 별개입니다. Ø180±2만으로 축 높이가 ±1mm 달라지며 타이어 압축·평면도·캐스터 편차가 추가됩니다. 높이조절/시밍 또는 탄성 지지와 실제 바퀴 하중 측정이 필요합니다.

배터리 더미는235×155×95입니다. 드라이버 더미를 Y85로 이동해 배터리와 겹치던9.5mm 영역을 제거했습니다. 판·브라켓·센서 마운트의 강도·체결·간섭 검토는 계속 필요합니다.

## 배터리 및 전원

일반4.2V 완충 리튬이온7S라면 최대 **29.4V**, 셀3.6V 공칭이면25.2V입니다. 3Ah 셀9P라는 가정에서27Ah/약680Wh입니다. 화학종 확인 전 이를 실제 팩 정격으로 쓰지 않습니다.

**18~30V는 모터 사용 범위이며 미선정 드라이버 허용전압이 아닙니다.** 29.4V에서30V까지0.6V만 남습니다. 회생제동 시 DC버스 상승, BMS 충전 차단/만충 상태, 배선 과도전압을 포함해 드라이버·제동저항/클램프·BMS를 함께 선정해야 합니다. SICK 최대입력28V를 넘으므로 배터리에 직결하지 않고 안정화24V DC/DC 전원을 계획합니다. 카메라/컴퓨터에는 별도5V 계통이 필요합니다. 스톨30A×2를 배터리전류60A로 단정하지 말고, 상전류와 DC입력전류/듀티/효율을 구분하여 BMS·배선·퓨즈를 선정합니다.

## STEP 재생성과 검증

```bash
pip install cadquery==2.5.2
python cad/amr_layout.py
```

GitHub Actions가 Rev05 STEP과 검증 JSON을 자동 생성해 저장합니다. 생성 후 STEP을 다시 열어85개 솔리드의 유효성/양의 체적,6개 바퀴의 실제 경계 Z0,타이어180×42.5/축 평면10을 검사합니다. 주기둥 가림을 포함한 2D 스캔면 표본1616점이 적어도 한 센서의 시야에 들어오는지 추가 검사합니다. 이는 연속360° 또는 실제 검출을 보증하지 않습니다. 이는 강도·주행 안정성·실물 부품의 완전한 형상 또는 전체 조립 간섭 검증을 의미하지 않습니다. 웹은 같은 `cad/parts.json`과 `cad/layout.json`을 사용하며 회전·TOP/FRONT·부품 숨기기·분해·PNG·개념 모션을 제공합니다. Three.js CDN 인터넷 연결이 필요합니다. Rev01~04 STEP은 이력용입니다.
